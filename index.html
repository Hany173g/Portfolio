Featured Project

Droply

Video-Sharing Platform Backend

Backend Developer

Droply is a RESTful API for a YouTube-like video-sharing platform. I designed and built the entire backend — from authentication and video processing pipelines to real-time watch tracking and a notification system — with an emphasis on secure, well-tested, production-style architecture.

Key Backend Features:
  • JWT authentication with access + refresh tokens
  • Background job processing with BullMQ for video uploads and notifications
  • Signed, expiring video URLs via Cloudinary (authenticated HLS streaming)
  • Watch session tracking with heartbeat-based, anti-cheat view counting
  • In-app notification system with light and broadcast queues
  • Rate limiting across auth, upload, and subscription endpoints
  • Language-aware content feed with automatic language detection
  • Unit and integration testing with Jest
